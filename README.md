# 🚧 Delivery Tracker

I'm building this fast because me and my coworkers are getting crushed every week.  
We're under pressure to rush, skip breaks, and still somehow hit unrealistic numbers — and people are getting written up, injured, or fired even when they follow the rules.

**Delivery Tracker** is my way to fight back.  
It logs our shifts, our drops, and our real workload — so we can prove what it actually takes to do this job safely.

---

## ⚡ What It Does (right now)

- Start/stop timers for each delivery drop  
- Saves data locally (works offline)  
- Tracks run start/end time, van info, and number of drops  
- Stores everything in a database — each user owns their own data  
- Mobile-friendly — built to be used on the go during runs
